# Changelog

All notable user-visible changes to the Gogs TOS application package.

## 0.13.3-1 — 2026-11-15

### Added
- First release. Gogs (`gogs/gogs:0.13.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8163 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/gogsdocker/`.
